[FIX] Node.js 26 ESM dynamic import() crash on Windows
[ROOT CAUSE] Node 26 rejects Windows absolute paths (D:\path) passed to dynamic import().
vite-node generates specifiers in 3 forms:
  A. D:\path\to\module (bare Windows path)
  B. file:\D:\path\to\module (malformed — Vite externalize + backslash)
  C. file:///D:/path/to/module (already correct)
pathToFileURL() built-in memperlakukan varian B sebagai path literal → hasil URL
rusak "file:///file:/D:/...".
[FIX]
  - scripts/normalize-specifier.mjs (baru): fungsi normalizeSpecifier() —
    strip prefix "file:" via regex, deteksi Windows absolute path, konversi
    ke "file:///D:/...". Non-Windows specifier dikembalikan as-is.
  - scripts/esm-loader.mjs: panggil normalizeSpecifier() di resolve hook.
  - scripts/patch-vite-node.mjs: inline logic normalizeSpecifier di
    importExternalModule() saat postinstall.
  - dev.bat: set NODE_OPTIONS=--loader file:///... otomatis.
